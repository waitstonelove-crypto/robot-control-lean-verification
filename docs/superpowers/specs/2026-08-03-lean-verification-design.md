## 1. 背景与目标

用户为机械臂控制方向博士生（NTU），在研项目为 ALMM+ASOA 统一 QP 框架（目标 IEEE TII）。手头有一份推导文档《完整公式推导_速度级与加速度级.md》，含速度级 42 公式与加速度级推广；并持有源论文：

> Ma, Xie, Zhan, Jiang, Liu & Liu, "Actual Shape-Based Obstacle Avoidance Synthesized by Velocity–Acceleration Minimization for Redundant Manipulators: An Optimization Perspective," IEEE TSMC: Systems, 53(10), 2023.

**目标**：用 Lean 4 + Mathlib 机器验证以下三部分公式的推导正确性：

1. **上篇**：速度级 42 公式（文档"论文原文"部分，实为混合来源课本内容）
2. **下篇**：加速度级推广（用户原创）
3. **论文公式** (1)–(36)（源论文，权威基准）

## 3. 核对发现（设计依据）

文档与源论文**不是**忠实转写关系，逐条比对结论：

| 文档声称 | 论文实际 | 结论 |
|---|---|---|
| 文档 (1)(2) 正/微分运动学 | 论文 (1)(2) 一致（记号 p vs r_E） | ✅ 一致 |
| 文档 (3) 雅可比列向量（旋量理论） | 论文 (3) 是加速度级运动学 r̈_E = J̇_Eθ̇ + J_Eθ̈ | ❌ 内容不同 |
| 文档 (4)–(9) 伪逆/零空间/梯度投影/通解 | 论文无这些公式（不用伪逆，用 QP+RNN） | ❌ 混入他源 |
| 文档 (16)–(19) 关节极限 h 函数/分段梯度 | 论文用 η⁻/η⁺ 统一化 (8)(9) | ❌ 机制不同 |
| 文档 (20)–(34) QP→VI→LVI→投影NN→Lyapunov | 论文 (27)(28) QP + (29)–(31) KKT/RNN + (32)–(36) 单调算子收敛 | ❌ 证明路线不同 |
| 文档 (35)–(38) 线段-球避障 | 论文 GJK 凸多面体 + ⊗ 算子 (10)–(17) | ❌ 方法不同 |
| 文档 (39) Li 函数 | 论文无；来自 ALMM（Yang et al., b2） | ❌ 他源内容 |

**推论**：验证时以论文为准修正符号与公式；文档三部分各自独立形式化，但公式编号在定理注释中交叉引用。

## 4. 形式化策略

### 4.1 抽象层级
不建模 DH/具体机械臂。所有运动学实体（J_E、J̇_E、J_C、u_CO、⊗ 算子）作为**符号矩阵/向量**，验证"代数推导层"：给定这些量及其假设，推导严格成立。数值仿真不验证。

### 4.2 数学对象
- 域：ℝ（Mathlib `Real`）
- 向量/矩阵：`Fin m → Fin n → ℝ`（Mathlib `Matrix`）
- 范数：欧氏范数；内积：标准内积
- 伪逆：Mathlib `Matrix.pinv`；另证行满秩时 `J† = Jᵀ(JJᵀ)⁻¹` 等价
- 投影算子：框约束显式解 `P_Ω(y) = max(l, min(y, h))`；非扩张性用 Mathlib 范数引理

### 4.3 明确不进 Lean 的边界
1. GJK 迭代算法本身（实现/数值）；但距离定义 (10)(11)(12)、最近点对性质形式化
2. **投影动力系统全局收敛**（Gao 2003 / Friesz 1999，即论文 Lemma 1）：`axiom` 引入，单文件集中标注引用来源。完全证明需 Hilbert 空间单调算子+指数稳定性理论，Mathlib 工具不成熟，超出本项目合理范围
3. 文档 (30) Lyapunov 推导：把"非扩张性 + 矩阵条件"下可证的部分严格化；其核心衰减不等式 `V̇ ≤ −2γηV` 在 Mathlib 中按可证程度处理，证不到的步骤同样以假设引入并标注
4. 数值内容（仿真参数、算例）不验证

### 4.4 定理注释规范
- 每条定理 doc-comment 引用公式编号：文档号（如 `doc (4)`）/ 论文号（如 `paper (4)`）
- 中英双语注释，方便论文引用与用户审阅
- 定理命名：`vel_*` / `acc_*` / `qp_*` / `pnn_*` / `paper_*` 前缀 + 语义名
